# xfce4-ddc-plugin

Xfce4-ddc-plugin is a plugin to the Xfce panel, version 4.16 or higher.
It allow control your monitor via DDC protocol

----

### Installation

From source code repository:

    % cd xfce4-ddc-plugin
    % ./build.sh

### Uninstallation

    % ninja uninstall -C build
